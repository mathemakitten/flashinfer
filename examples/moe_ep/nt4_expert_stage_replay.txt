Mixed FC1/FC2 geometry prototype (2026-10-29)
-------------------------------------------
--fc12-mixed-geometry keeps FC1 M128/N256/K128 and changes only FC2
N to 128 inside the same lean fused kernel. Diagnostic-only; the communicating
wrapper rejects this option until the lean implementation is qualified.

The two phases share A storage and the existing FC1-sized B allocation. FC2
uses a smaller B/SFB view with the original inter-stage strides, so neither
phase can overwrite another stage's live data. The B barrier expects the FC2
byte count; FC1 adds the remaining expected bytes before issuing either load.
FC1's accumulator layout and readiness threshold remain unchanged. FC2 uses
half-width MMA and output tiles and releases the accumulator only after all
its reads; the previous first-subtile early release is unsafe with unequal
phase widths. This conservative handoff is part of the measured candidate.

The harness brackets group1024 N256 and group1024 mixed tiles with the original
group512 controls. It requires exact valid-row FC1 bytes, FC1 scales, final
output and poisoned graph replay. No numerical tolerances are widened. Four
saved rank-local routing distributions run in separate processes; this is not
an EP communication test or an E2E benchmark. Run:
  bash examples/moe_ep/nt4_fc12_mixed_geometry.sh 152
